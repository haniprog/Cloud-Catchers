# Cloud Catchers

Cloud Catchers is a small browser-based arcade game built with JavaScript, where the player guides a character across floating clouds, dodges hazards, collects coins, and advances through levels.

## About the project
This project is a single-player platformer game with a polished sky-themed interface. It combines gameplay, audio, progress saving, and simple AI-driven level sequencing in one compact experience.

## The problem it solves
It provides a fun and accessible game experience while also demonstrating how to build a complete interactive project with game logic, rendering, persistence, and desktop packaging.

## Technologies used
- HTML, CSS, and JavaScript
- Canvas-based game rendering
- Electron for the desktop wrapper
- JSON-based save data for progress and settings
- Custom AI algorithms such as BFS, DLS, and IDS for route generation

## Contributions
- Built the core game loop and main gameplay systems
- Implemented cloud platforms, movement, hazards, scoring, and level progression
- Added audio, save/load support, and UI screens
- Integrated AI-based path and obstacle generation for the game flow

## How to run
1. Install Node.js and npm if needed.
2. Open the project folder in a terminal.
3. Run:
   ```bash
   npm install
   npm start
   ```
You can also open the web entry point in a browser if you want to try the non-Electron version.

## Interface
The game features a bright, colorful sky backdrop, floating cloud platforms, a character jumping between clouds, collectible coins, and obstacles that create a playful but challenging arcade feel.
